Do Zero ao Expert

Aprenda a usar o npx skills — o gerenciador de habilidades para agentes de IA. Como o npm mas para skills de agentes.

Instale, crie e compartilhe skills que transformam agentes genéricos em especialistas. Claude Code, Cursor, Copilot, OpenCode e mais 45+ agentes suportados.

# Como npm instala pacotes Node.js...
npm install react
# Skills CLI instala habilidades para agentes IA
npx skills add vercel-labs/agent-skills
