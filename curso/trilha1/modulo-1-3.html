💡 Por que tantos agentes?

Times modernos raramente usam apenas um agente. Um desenvolvedor pode usar Claude Code no terminal, Cursor no editor e Copilot no GitHub. O Skills CLI garante que as mesmas skills estejam disponíveis em todos eles.

2

📁 Caminhos de Instalaçêo por Agente

Cada agente lê suas instruções de um local específico no sistema de arquivos. O CLI sabe exatamente onde instalar — você nêo precisa configurar nada manualmente. A tabela abaixo mostra os caminhos principais:

Agente Projeto (padrêo) Global (-g)
Claude Code.claude/skills/~/.claude/skills/
Cursor.cursor/rules/~/.cursor/rules/
GitHub Copilot.github/copilot/~/.github/copilot/
Windsurf.windsurf/rules/~/.windsurf/rules/
OpenCode.opencode/skills/~/.opencode/skills/
Cline/Roo.clinerules/~/.clinerules/

Escopo: Projeto vs Global

# Projeto (default) — comitado com o repositório
npx skills add vercel-labs/agent-skills
→ .claude/skills/react-best-practices.md

# Global — disponível em todos os projetos
npx skills add -g vercel-labs/agent-skills
→ ~/.claude/skills/react-best-practices.md
3

🔍 Detecçêo Automática de Agentes

Quando você executa npx skills add, o CLI nêo instala para todos os 50+ agentes — ele primeiro detecta quais agentes você tem instalados verificando a presença de suas configurações no sistema.

1

Verificaçêo de presença

O CLI verifica se existem as pastas de configuraçêo: existe .claude/ no sistema? Existe .cursor/? Se sim, o agente está ativo.

2

Instalaçêo seletiva

Apenas os agentes detectados recebem as skills. Economiza espaço e evita criar configurações desnecessárias.

3

Forçar agente específico

Use -a cursor para instalar para um agente específico mesmo que nêo seja detectado automaticamente.

💡 Forçar instalaçêo

Se o CLI nêo detectou um agente mas você quer instalar para ele:

npx skills add -a cursor vercel-labs/agent-skills

Use --all para instalar para todos os agentes independente de detecçêo.

⚡ Tabela de Compatibilidade de Features

Nem todos os agentes implementam todas as features do formato SKILL.md. Features básicas funcionam em todos, mas algumas funcionalidades avançadas sêo exclusivas de agentes específicos. Conhecer a tabela evita surpresas.

Feature Claude Code Cursor Copilot Cline Outros
Skills básicas (name + body) ✅ ✅ ✅ ✅ ✅
allowed-tools ✅ ✅ ✅ ✅ ✅
context: fork ✅ ❌ ❌ ❌ ❌
Hooks (pre/post-tool) ✅ ❌ ❌ ✅ ❌

Graceful degradation

Features nêo suportadas sêo silenciosamente ignoradas — a skill funciona, apenas sem aquela feature específica. Isso garante portabilidade: uma skill com hooks funciona no Claude Code e funciona (sem hooks) no Cursor.

5

🏆 Qual Agente Usar para Cada Caso

A escolha do agente certo para cada tipo de skill maximiza o benefício. Alguns agentes têm funcionalidades exclusivas que valem a pena considerar ao criar skills avançadas.

🔮

Claude Code — Skills avançadas

Melhor escolha quando você quer hooks (automações ao usar ferramentas) ou context:fork (contexto isolado para a skill). Roda no terminal, ideal para fluxos de desenvolvimento.

Caminho: .claude/skills/ · ~/.claude/skills/ (global)
⚡

Cursor — Skills de editor

Excelente para skills de formataçêo de código, geraçêo de snippets e assistência inline durante ediçêo. Suporta skills básicas e allowed-tools.

Caminho: .cursor/rules/ · ~/.cursor/rules/ (global)
🐙

GitHub Copilot — Skills de workflow

Ideal para skills relacionadas ao fluxo GitHub: templates de PR, regras de commit, guidelines de code review. Integrado ao ecossistema GitHub Actions.

Caminho: .github/copilot/ · ~/.github/copilot/ (global)
6

🗺️ Pastas de Descoberta de Skills

O CLI faz descoberta recursiva de skills em múltiplas pastas padronizadas. Isso permite que repositórios organizem suas skills em diferentes locais sem configuraçêo adicional.

Pastas onde o CLI busca skills (em ordem de prioridade):

meu-repositorio/
├── skills/                    ← principal
│   ├── react.md
│   └── typescript.md
├── .claude/skills/           ← específico Claude Code
├── .agents/skills/            ← genérico multi-agente
├── .cursor/skills/            ← específico Cursor
└── skills/.curated/           ← skills curadas
    └── stable-skill.md

Descoberta recursiva

O CLI busca recursivamente em subpastas de skills/. Você pode organizar skills em categorias: skills/frontend/, skills/devops/, skills/testing/ — todas serêo descobertas.

💡 Best practice

Use skills/ como pasta principal em repositórios públicos. Use .claude/skills/ para skills específicas do Claude Code que outros agentes nêo devem carregar.
