🚀 Casos de Uso: DevOps e Produtividade

Skills de deploy, Docker, documentação, find-skills e integrações com Linear, Notion, Slack.

1

🐳 Skills de deploy e Docker

Skills de DevOps ensinam práticas de Docker (multi-stage builds, segurança, .dockerignore), CI/CD (GitHub Actions, stages, approvals) e deploy seguro.

Automatizando operações

Erros de deploy custam caro. Uma skill de deploy que inclui checklist pré-produção (testes, migrações, rollback plan) reduz incidentes dramaticamente.

💡 Conceitos-chave

Docker · multi-stage · CI/CD · GitHub Actions · deploy seguro · checklist · rollback

2

📚 Skills de documentação

Skills de documentação ensinam ao agente: quando gerar/atualizar README, como escrever JSDoc, como manter CHANGELOG.md e como documentar APIs com OpenAPI.

Agente que documenta automaticamente

Documentação é frequentemente ignorada por ser tediosa. Com uma skill, o agente documenta conforme desenvolve, mantendo a base de código sempre documentada.

💡 Conceitos-chave

README · JSDoc · CHANGELOG · OpenAPI · documentação inline · atualização automática

3

🔍 Skill find-skills: descoberta automática

A skill find-skills, quando instalada, faz o agente sugerir ativamente a instalação de skills quando percebe que o usuário está fazendo algo que poderia ser melhorado por uma skill.

A skill meta-skill

find-skills transforma o agente em um curador ativo de seu próprio aprendizado. Em vez de você saber todas as skills disponíveis, o agente te sugere o que instalar.

💡 Conceitos-chave

find-skills · descoberta proativa · sugestão · meta-skill · curadoria ativa · npx skills find

4

📋 Integração com Linear e Jira

Skills de Linear/Jira ensinam ao agente: criar issues no formato correto, relacionar commits com issues, atualizar status automaticamente e gerar relatórios de progresso.

Skills de gerenciamento de projeto

Integrar o agente com ferramentas de gerenciamento elimina a necessidade de atualizar issues manualmente. O agente faz isso como parte natural do seu fluxo de trabalho.

💡 Conceitos-chave

Linear · Jira · issues · commits · status · relatórios · ComposioHQ

5

💬 Integração com Notion e Slack

Skills de Notion/Slack ensinam ao agente: atualizar documentação no Notion automaticamente, enviar notificações de deploy no Slack, criar relatórios de sprint.

Skills de comunicação

Times distribuídos dependem de comunicação assíncrona. Skills de Slack/Notion garantem que todos recebam as informações certas no momento certo, sem trabalho manual.

💡 Conceitos-chave

Notion · Slack · notificações · documentação automática · comunicação · times distribuídos

6

⚡ Criando skills de produtividade personalizadas

O caso de uso mais poderoso: criar skills específicas para os processos únicos do seu time. Processos de code review, standup reports, estimativas de tempo.

Skills do seu workflow

Nenhum repositório público conhece seus processos específicos. Skills personalizadas são onde o investimento em aprender Skills CLI paga o maior dividendo.

💡 Conceitos-chave

skills personalizadas · workflow próprio · processo interno · ROI máximo · diferencial competitivo
