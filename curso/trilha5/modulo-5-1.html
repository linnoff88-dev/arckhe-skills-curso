📁 Caminhos de instalação no Claude Code

Claude Code busca skills em .claude/skills/ (projeto) e ~/.claude/skills/ (global). O CLI instala nesses caminhos automaticamente.

Onde o Claude Code procura

Conhecer os caminhos permite inspecionar manualmente e resolver conflitos entre skills de projeto e globais.

💡 Conceitos-chave

.claude/skills/ · ~/.claude/skills/ · symlinks · inspeção manual

2

⚡ context: fork em detalhes

context: fork cria subconversa completamente isolada. A skill opera com seu próprio contexto, histórico e estado.

Feature exclusiva mais poderosa

Ideal para transformações: a skill analisa código em contexto isolado e retorna apenas o resultado processado.

💡 Conceitos-chave

context:fork · isolamento completo · subconversa · estado independente · resultado limpo

3

🎣 Hooks: pre-tool e post-tool

Hooks pre-tool executam antes de cada uso de ferramenta (validação, logging). Hooks post-tool executam depois (registro, cleanup).

Automação por evento

Use pre-tool para validar antes de executar. Use post-tool para auditar ações realizadas.

💡 Conceitos-chave

pre-tool · post-tool · validação · logging · auditoria · automação

4

📦 Hook pre-compact

O hook pre-compact executa antes do Claude Code compactar o contexto. Permite salvar estado importante.

Antes da compactação

Em sessões longas, contexto é compactado. O pre-compact garante que informações críticas são preservadas.

💡 Conceitos-chave

pre-compact · compactação · preservação de estado · sessões longas

5

🔄 Como o Claude Code carrega skills

O Claude Code lê todos os .md em .claude/skills/ e os inclui no contexto do sistema. A description é usada para ativação.

O processo de carregamento

Entender o processo ajuda a diagnosticar problemas: skill não ativada, conteúdo não aplicado, conflitos.

💡 Conceitos-chave

carregamento · contexto do sistema · .md files · diagnóstico · conflitos

💻 Exemplos práticos com Claude Code

Exemplos: skill de review com hooks de logging, skill de deploy com pre-tool validation, skill de documentação com context:fork.

Casos de uso reais

Ver exemplos concretos inspira a criar skills avançadas para seu próprio fluxo de trabalho.

💡 Conceitos-chave

exemplos práticos · review com hooks · deploy validation · context:fork · casos reais
