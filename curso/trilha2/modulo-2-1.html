📦 Instalaçêo Básica com Shorthand GitHub

A forma mais simples e usada é o shorthand owner/repo. O CLI resolve automaticamente para a URL completa do GitHub, faz o download e instala para os agentes detectados.

Exemplos de instalaçêo básica:

# Instalaçêo mais simples (shorthand)
npx skills add vercel-labs/agent-skills

# O CLI detecta agentes e pergunta:
? Instalar 12 skills para: claude, cursor, copilot? (Y/n)

# Com -y: pula a confirmaçêo
npx skills add -y vercel-labs/agent-skills

✓ 12 skills instaladas para claude
✓ 12 skills instaladas para cursor
✓ 12 skills instaladas para copilot

Como o shorthand é resolvido

# owner/repo → resoluçêo automática
vercel-labs/agent-skills
→ https://github.com/vercel-labs/agent-skills
→ GitHub API → lista de skills
→ download → instalaçêo

💡 Repositórios mais populares

  • npx skills add vercel-labs/agent-skills
  • npx skills add anthropics/skills
  • npx skills add ComposioHQ/awesome-claude-skills

🔗 Todos os Formatos de Fonte

O comando skills add aceita quatro formatos de fonte, cada um adequado a um cenário diferente. Conhecer todos expande muito o que você pode fazer com o CLI.

1

Shorthand GitHub

npx skills add vercel-labs/agent-skills

Mais simples. Resolve automaticamente para GitHub. O formato é owner/repo.

2

URL Completa do GitHub

npx skills add https://github.com/org/repo

URL completa. Também funciona com GitLab e Bitbucket com suas URLs próprias.

3

URL de Skill Específica

npx skills add https://github.com/org/repo/tree/main/skills/minha-skill

Instala apenas uma skill específica apontando para o caminho exato no repositório.

4

Path Local

npx skills add ./meu-projeto-local

Instala do sistema de arquivos local. Ideal para desenvolvimento e skills internas.

3

🌍 Flag -g: Instalaçêo Global

A flag -g (ou --global) muda o destino da instalaçêo de ./agente/skills/ para ~/agente/skills/. Skills globais ficam disponíveis em qualquer projeto no seu sistema.

📁 Escopo Projeto (padrêo)

npx skills add owner/repo
→ .claude/skills/skill.md
→ .cursor/rules/skill.md

Comitado com o projeto. Toda a equipe usa as mesmas skills.

🌍 Escopo Global (-g)

npx skills add -g owner/repo
→ ~/.claude/skills/skill.md
→ ~/.cursor/rules/skill.md

Nêo versionado. Suas preferências pessoais em todos os projetos.

💡 Quando usar cada escopo

  • →Projeto: Convenções de código, stack do projeto, processo do time
  • →Global: Estilo pessoal, idioma, ferramentas preferidas, produtividade
4

🎯 Flag -a: Instalar para Agente Específico

A flag -a (ou --agent) especifica exatamente para qual agente instalar, sobrescrevendo a detecçêo automática. Aceita um único agente ou uma lista separada por vírgula. 

# Instalar só para Claude Code
npx skills add -a claude vercel-labs/agent-skills

# Instalar para Claude e Cursor
npx skills add -a claude,cursor vercel-labs/agent-skills

# Global + agente específico
npx skills add -g -a cursor vercel-labs/agent-skills

Identificadores de agentes

claude ← Claude Code
cursor ← Cursor
copilot ← GitHub Copilot
windsurf ← Windsurf
cline ← Cline
opencode ← OpenCode
5

🔩 Flag -s: Instalar Skills Específicas

A flag -s (ou --skill) permite instalar apenas skills selecionadas de um repositório. Útil quando um repositório tem muitas skills mas você precisa de apenas algumas. 

# Ver skills disponíveis antes de instalar
npx skills add --list vercel-labs/agent-skills
Available: react-best-practices, nextjs-routing,
           design-system, git-commit-style, ...

# Instalar só react e nextjs
npx skills add -s react-best-practices,nextjs-routing \
  vercel-labs/agent-skills

💡 Use --list primeiro

Antes de instalar de um novo repositório, use --list para ver quais skills estêo disponíveis. Assim você pode escolher exatamente o que precisa com -s.

6

🤖 --all e -y para Automaçêo CI/CD

Para pipelines de CI/CD e scripts de setup, o comando deve ser nêo-interativo. As flags --all e -y garantem instalaçêo completamente automatizada.

Exemplo de GitHub Actions workflow:

- name: Install Agent Skills
  run: |
    npx skills add --all -y vercel-labs/agent-skills
    npx skills add --all -y ./our-internal-skills

--all

Instala para TODOS os agentes suportados, independente de detecçêo automática. Útil em ambientes de CI onde os agentes nêo estêo instalados mas queremos os arquivos.

-y / --yes

Responde "yes" automaticamente a todas as confirmações. Essencial para scripts nêo-interativos. Combine com --all para instalaçêo completamente automática.
