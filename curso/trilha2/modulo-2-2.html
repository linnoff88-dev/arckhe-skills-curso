🔎 skills find: Busca Interativa

O comando npx skills find busca skills no ecossistema público do skills.sh. Sem argumentos, abre uma interface interativa estilo fzf. Com keyword, filtra diretamente. 

# Busca interativa (abre fzf-like UI)
npx skills find

# Busca por keyword
npx skills find react
npx skills find typescript
npx skills find "code review"

# Resultado:
→ vercel-labs/agent-skills: react-best-practices (100K installs)
→ anthropics/skills: frontend-design (50K installs)
→ comunidade/react-skills: react-hooks (30K installs)

O que o find mostra

  • •Nome da skill e repositório — Onde encontrar e instalar
  • •Install count — Popularidade como indicador de qualidade
  • •Description — O que a skill faz
  • •Agentes compatíveis — Para quais agentes funciona

💡 Regra de ouro

Antes de criar uma skill, sempre execute npx skills find [sua-necessidade]. Pode já existir uma skill perfeita. Reutilizar é sempre melhor que criar.

2

📋 skills list: Inventário de Skills

O comando npx skills list mostra todas as skills instaladas, organizadas por escopo (projeto/global) e por agente. Essencial para auditar periodicamente o que está configurado. 

# Listar tudo
npx skills list

📁 Projeto (.claude/skills/)
  ✓ react-best-practices [symlink] ← vercel-labs/agent-skills
  ✓ nextjs-routing [symlink] ← vercel-labs/agent-skills
  ✓ deploy-interno [copy] ← ./internal-skills

🌍 Global (~/.claude/skills/)
  ✓ find-skills [symlink] ← vercel-labs/agent-skills
  ✓ meu-estilo [copy] ← local

# Só globais
npx skills list -g

# Só projeto
npx skills list -p

Quando auditar

  • •Ao adicionar um novo desenvolvedor ao time
  • •Antes de uma release importante
  • •Quando o agente está gerando código inconsistente
  • •Mensalmente, como boa prática

💡 Dica de equipe

Adicione npx skills list ao seu README de setup do projeto. Novos devs saberêo exatamente quais skills o time usa.

3

⬆️ skills update: Mantendo Atualizado

Skills evoluem. A comunidade melhora continuamente as skills populares. O comando npx skills update sincroniza suas skills com as versões mais recentes dos repositórios fonte. 

# Atualizar todas as skills
npx skills update

# Atualizar skill específica
npx skills update react-best-practices

# Atualizar só globais
npx skills update -g

# Resultado:
✓ react-best-practices: v1.2 → v1.3 (3 linhas alteradas)
✓ nextjs-routing: já está atualizado
✓ deploy-interno: atualizado (cópia local)

Como o update funciona por método

🔗 Symlinks

Faz git pull no repositório fonte clonado. Todos os symlinks atualizam automaticamente pois apontam para a mesma fonte.

📋 Cópias

Baixa a versêo mais recente e substitui as cópias locais. Cada cópia é atualizada individualmente.

4

🗂️ Controlando Escopo com -g e -p

As flags -g e -p sêo transversais: funcionam com list, update e remove. Sem flag, os comandos operam em ambos os escopos simultaneamente.

📁
-p / --project

Apenas skills do projeto (./ path)

🌍
-g / --global

Apenas skills globais (~/ path)

🔄
(sem flag)

Ambos os escopos

# Update apenas globais (nêo toca no projeto)
npx skills update -g

# List apenas projeto (para auditoria de PR)
npx skills list -p

# Remove apenas globais
npx skills remove -g skill-obsoleta
5

🔄 Symlink vs Copy: Quando Usar Cada Um

A escolha entre symlink (padrêo) e copy (com --copy) afeta como as skills sêo armazenadas e atualizadas. Entender a diferença evita problemas em ambientes específicos.

🔗 Symlink (Recomendado)

  • ✓Uma fonte canônica compartilhada
  • ✓Update faz git pull na fonte
  • ✓Menos espaço em disco
  • ✓Todos os agentes veem a mesma versêo

📋 Copy (--copy)

  • ✓Funciona em Windows (symlinks limitados)
  • ✓Funciona em filesystems remotos/NFS
  • ✓Independente da fonte após instalaçêo
  • →Update substitui as cópias manualmente
# Usar copy quando symlinks nêo funcionam
npx skills add --copy vercel-labs/agent-skills
6

🎮 Fluxo Completo de Gestêo de Skills

Combinando find, add, list e update, você tem um ciclo completo de gestêo de conhecimento do agente. Aqui está o fluxo recomendado para times:

1

Descoberta

npx skills find [tecnologia]

Encontre skills relevantes antes de criar do zero

2

Instalaçêo

npx skills add owner/repo

Instale as skills encontradas

3

Auditoria

npx skills list

Periodicamente, verifique o que está instalado

4

Manutençêo

npx skills update

Semanalmente ou antes de sprints importantes
